# ITX Front-End Test — Tienda de móviles

Mini-aplicación SPA para comprar dispositivos móviles: listado con búsqueda en tiempo real (PLP) y detalle con selección de opciones y cesta (PDP).

## Plan

1. Proyecto Vite + React (JavaScript), con scripts `start`, `build`, `test` y `lint`.
2. Capa de API con caché en cliente (expiración de 1 hora) y normalización de datos.
3. PLP: rejilla adaptable (máximo 4 por fila) y búsqueda por marca y modelo.
4. PDP: imagen, descripción, selectores de almacenamiento y color, botón Añadir.
5. Cabecera con breadcrumbs y contador de la cesta persistido.
6. Tests, lint y documentación final.
